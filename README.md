# Табулирование многочлена по схеме Горнера (Java Swing)

Учебная лабораторная работа по созданию графического интерфейса пользователя (GUI) на Java Swing для вычисления значений многочлена с использованием **схемы Горнера**, визуализации данных в таблице с кастомным рендерингом и возможностью экспорта результатов.

## 🚀 Описание функционала

Программа позволяет вычислять значения многочлена произвольной степени на заданном интервале изменений переменной $X$ с фиксированным шагом. 

### Основные возможности:
* **Динамический расчет**: вычисление значений многочлена по схеме Горнера.
* **Кастомная визуализация таблицы (`JTable`)**:
  * Подсветка строк синим цветом при поиске точного значения (функционал «иголки» в стоге сена).
  * Подсветка оранжевым цветом, если сумма цифр целой части значения делится на 10.
  * Подсветка бирюзовым цветом для ячеек, удовлетворяющих условию краевой симметрии.
* **Опциональный 3-й столбец**: чекбокс «3 столбец» динамически перестраивает модель данных, добавляя проверку на совпадение первой и последней значащей цифры результата (краевая симметрия).
* **Экспорт данных**:
  * Сохранение результатов табулирования в удобочитаемый текстовый формат (`.txt`).
  * Сохранение точек в бинарный файл (`.bin`) для последующего построения графиков.

## 📂 Структура проекта

* `Main.java` — главное окно приложения (`JFrame`), содержащее меню управления, поля ввода параметров интервала ($X_{from}$, $X_{to}$, шаг), кнопки вычислений и обработчики событий.
* `GornerTableModel.java` — модель таблицы (`AbstractTableModel`), отвечающая за хранение границ интервала, шага, коэффициентов и за непосредственный расчет значений.
* `GornerTableCellRenderer.java` — кастомный компонент отображения ячеек таблицы (`TableCellRenderer`), реализующий логику цветовой подсветки строк по заданным условиям.

## 🛠️ Запуск приложения

Программа принимает коэффициенты многочлена в качестве аргументов командной строки (начиная со старшей степени к младшей).

### Компиляция:
```bash
javac Main.java GornerTableModel.java GornerTableCellRenderer.java
```

### Пример запуска:
Для табулирования многочлена $3X^2 + 2X + 1$:
```bash
java Main 3.0 2.0 1.0
```

## 📋 Требования
* JDK 8 или выше
* Поддержка графической оболочки (компоненты `javax.swing` и `java.awt`)
